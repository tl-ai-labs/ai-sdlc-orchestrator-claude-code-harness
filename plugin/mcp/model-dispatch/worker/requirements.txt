# Python dependencies for gemini_worker.py — the agent behind the
# `antigravity-worker` adapter. Installed into a dedicated virtualenv by
# verify-setup.mjs --enable-agent.

# Exact pin. The SDK has changed what its usage totals mean between releases
# (0.1.9 counts cached input inside prompt_token_count; 0.1.16 counts it on
# top), and the costs this plugin reports are only right for versions checked
# against Google's own token counter — see AGY_USAGE_SEMANTICS in
# src/delegation/workerProcess.ts. Raise this pin only after the same check
# adds the new version there; an unchecked version is billed on the larger
# reading and logged as agsdk.usage_semantics_unverified.
google-antigravity==0.1.16

# Requires Python >= 3.10. macOS ships /usr/bin/python3 as 3.9;
# verify-setup.mjs resolves an explicit >= 3.10 interpreter by version-suffixed
# name (python3.13, python3.12, ...) rather than trusting bare `python3`.
#
# Homebrew wrinkle: some Homebrew Python builds link `pyexpat` against a
# libexpat that is not installed. If `import google.antigravity` fails with an
# expat error:
#
#   brew install expat
#   export DYLD_LIBRARY_PATH=/opt/homebrew/opt/expat/lib
